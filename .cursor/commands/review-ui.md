用 Task 工具调起 **ui-conventions-reviewer** 子 agent，按 `.cursor/agents/ui-conventions-reviewer.md` 的规程审当前改动。

提示里要包含：

- 仓库路径 `/home/banch/dev73info/user-client`。
- 审查范围：默认是当前未提交的改动（含未跟踪的新文件）；如果用户在这次命令后附带了文件路径或页面名，就以那个为准。
- 明确要求它按那份规程的 13 条逐条检查，并输出「必须改 / 建议改 / 待确认」三档，每条带 `文件:行号` 与具体改法。

拿到结果后，用中文向用户复述**最关键的三到五条**（不要整段转贴），并说明哪些是必须改的。
如果它报告「未发现违规」，照实说，并列出它实际检查了哪些文件——**不要为了让回复显得有内容而编造问题**。
