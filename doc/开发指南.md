## 一、命令

| 命令 | 作用 |
| --- | --- |
| `pnpm dev` | 启动 dev server（默认 5173，被占用会自动递增） |
| `pnpm build` | 生产构建，串起 `generate:sitemap` → `type-check` → `build-only` |
| `pnpm build-only` | `vite build` + `scripts/generate-seo-pages.mjs` |
| `pnpm type-check` | `vue-tsc --build` |
| `pnpm preview` | 预览构建产物 |
| `pnpm test:unit` | vitest（`vitest.config.ts`，用例在 `src/__tests__/`） |
| `pnpm test:e2e` | playwright（`playwright.config.ts`，用例在 `e2e/`） |
| `pnpm lint` | `lint:oxlint` + `lint:eslint`，两者都带 `--fix` |
| `pnpm format` | prettier 写 `src/` |
| `pnpm generate:sitemap` | 只生成 sitemap |
| `pnpm submit:indexnow` / `pnpm submit:baidu` | 向搜索引擎提交 URL |

## 二、两个环境前提

1. **必须用 POSIX shell 跑。** `dev`、`build`、`build-only`、`type-check` 等脚本以 `env -u NODE_USE_ENV_PROXY ...` 开头，Windows 原生 cmd / PowerShell 跑不了，要用 WSL 或 Git Bash。
2. **Node 版本有下限**：`engines` 要求 `^20.19.0 || >=22.12.0`，包管理用 pnpm。

## 三、依赖顺序

`package.json` 里 `tags-wasm` 是 `link:../tags-wasm/pkg`。`pkg/` 被 `tags-wasm/.gitignore` 忽略、不进仓库，所以**新克隆的仓库必须先构建 `tags-wasm` 产出 `pkg/`，再 `pnpm install`**，否则这个依赖解析不到。重建方式见 [tags-wasm/doc/构建与集成.md](../../tags-wasm/doc/构建与集成.md)。

## 四、dev 代理

`vite.config.ts` 里硬编码了目标 `http://127.0.0.1:8080` 和一组代理前缀（全部带 `changeOrigin` 与 `ws`）：

```
/api  /auth  /coupons  /public/requirements  /realname  /requirements
/tickets  /payments  /settings  /resources/resources  /resources/tags  /uploads
```

这些是**后端真实路径**的前缀，不是 `src/shared/api/url.ts` 里的前端路径——两套前缀同时存在是这个项目最容易绕晕的地方。要新增代理前缀时，先确认它属于哪一套。

## 五、环境变量

| 变量 | 用途 |
| --- | --- |
| `VITE_API_BASE_URL` | 接口基地址，留空表示同源（走 dev 代理） |
| `VITE_ROUTER_MODE` | `history` 时用 history 路由，否则 hash |
| `VITE_DEV_AUTO_LOGIN_USERNAME` / `VITE_DEV_AUTO_LOGIN_PASSWORD` | 本地自动登录（见下） |

## 六、本地自动登录

复制 `.env.local.example` 为 `.env.local`，填两个变量：

```
VITE_DEV_AUTO_LOGIN_USERNAME=...
VITE_DEV_AUTO_LOGIN_PASSWORD=...
```

`.env.local` **不入库**，且只放可丢弃的开发账号。模板里预置的是一组演示账号凭据。

## 七、踩坑速记

- 改完 `tags-wasm` 的 Rust 源码必须重建 `pkg/`，否则前端仍跑旧的 WASM。
- `auto-imports.d.ts`、`components.d.ts` 是生成物但入库，改代码后出现这两个文件的 diff 属正常。
- 401 失效令牌会自动登出并弹登录框，这是设计行为（改密后旧令牌即失效），排查时不要当成 bug。
