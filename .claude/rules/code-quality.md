# 代码质量与结构约束（Web 应用仓）

> 正本：根仓 `.claude/rules/前端标准化.md`。本文件是执行版，只写**本仓提交前必须满足的硬约束**。

## 一、结构预算（`pnpm check:frontend` 拦）

| 对象 | 上限 |
| --- | --- |
| `src/views/**/*.vue`（视图） | **300 行** |
| 其它 `.vue`（组件） | 400 行 |
| `.ts` | 300 行 |
| 单个视图直接 import 的 `api/` 模块 | **3 个** |

超了**先拆再提交**；新代码不许进基线。存量登记在 `frontend-baseline.json`，**只减不增**——
修好一条就从基线里删一条（脚本会提示过期条目，顺手删）。

## 二、设计令牌：不写裸色值

- 组件层只用令牌（`var(--73-*)` 或本仓既有令牌）；裸色值（`#rrggbb` / `rgb()` / `hsl()`）由 `check:frontend` 拦。
- 令牌的最终来源是 `../ui_73info` 的 `tokens.css`；本仓只在样式入口做映射，**不要在页面里另挑一个「差不多」的颜色**。
- 裸色值存量按文件登记在基线里，改到哪个文件就把那个文件的裸色值顺手清掉。

## 三、响应式断点只有三档

| 档位 | 宽度 |
| --- | --- |
| 手机 | `max-width: 640px` |
| 平板 / 手机横屏 | `max-width: 900px` |
| 宽屏 | `max-width: 1180px` |

- `639.98px` 这类取整写法按 ±1px 视为合规；其它档位（720 / 768 / 960 / 1024 …）**不许新增**，
  存量进基线、改造到该视图时一并改掉。
- 断点的语义是「布局怎么塌」，字号微调用 `clamp()` 或令牌，**不新增断点**。
- 改巨型视图时，原来挂在 `@media` 里的规则必须跟着搬到对应子组件，否则手机端会**静默塌掉**；
  验收时手机档（640）截图是硬要求。

## 四、接口与错误码

- 请求一律走本仓统一请求层（`src/api/http*.ts` 这类），**不要在组件里直接 `fetch`**。
- 错误**按 `code` 分支，不按 `message` / 文案匹配**——文案会改，错误码不会。`HttpError` 带 `code` 与 `field`，
  页面直接读 `err.code`，不要自己再解析一次响应体。
- 业务错误码的事实源是后端 `crates/platform/src/error_codes.rs`；前端真正要分支的那几条登记在本仓 `api` 层一份清单里，
  不要在页面里写字面量。
- `HTTP_<状态码>` 是后端兜底值，只用来区分「业务问题 / 框架兜底」，不拿它做具体业务分支。

## 五、契约类型

契约生成物已接入：`src/api/generated/openapi.json`（后端 `openapi.json` 的副本）+
`src/api/generated/schema.d.ts`（`pnpm contract:write` 生成），`pnpm contract:check` 已是硬门禁
（生成物与 spec 不一致直接红）。

- **不要手写「像契约」的类型**：响应 / 请求体形状一律 `components['schemas'][...]`。
  字段收窄（如 `status` 收窄成字面量联合）可以叠在生成物上写，但形状本身不许另抄一份。
- 后端 spec 更新后：换 `openapi.json` → `pnpm contract:write` → 按域改调用点，别只换文件不改消费方。
- 契约里**没有的能力**不要留调用点：要么删入口，要么在页面上明写「未上线」；
  不许用 Mock 顶替，也不许把 401/403/500 吞成空列表。
- 生成物与 `src/mock/**` 都算「跟着契约走」的代码：spec 变了要一起改，别只在 `api/*.ts` 里改一半。

## 六、单测

- Vitest；新增组件 / composable 要有交互用例，改到已被测试覆盖的行为要同步改测试。
- `pnpm test:ci` 必须绿；`skip` 或暂时跳过的用例要在 PR 里写明原因与恢复计划。

## 七、lint 与格式

- `pnpm lint:check`（`--max-warnings=0`）必须绿；**不要手写 `eslint-disable`**——
  存量抑制登记在 `eslint-suppressions.json`，只减不增（修好一处 `pnpm exec eslint . --prune-suppressions` 清账）。
- 格式只要求本次涉及的文件合规；**不要为了过格式门禁整仓重排**，那样 PR 里全是噪声。
